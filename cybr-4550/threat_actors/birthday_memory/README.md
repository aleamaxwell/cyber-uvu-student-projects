This project was originally copied from HVAAndres with the express intent to find vulnerabilities in the code and practice skills gained from his Cybr-4550 course at Utah Valley University. 
Most vulnerabilities (listed below) and the report on such can be found on the Exploring Bad Code document located in the main folder. To repeat any of the vulnerabilities use the tool that is listed in the vulnerabilities record in said document.
The vulnerabilities found were:
Proxy-addr vulnerable to IP spoofing via IPv4-mapped IPv6 trust subnet
Personal Identifying Information found on the Main Websites page
Environment variable NODE_TLS_REJECT_UNAUTHORIZED which disabled TLS verification
shell-quote: 'quote()" command injection via a line terminator in a token after a '{ comment }' token
A tag missing the 'integrity' sub resource integrity attribute
Denial of Service via unhandled decompression stream error
Denial of Service via unhandled expect ion during array serialization
The link points to a plaintext HTTP URL.
